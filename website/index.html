The documents you actually open, in one small app.

Writan opens Word, PowerPoint, Excel, CSV, PDF, Markdown, text and image files, each in a tab of one window. Use it in place of Word, PowerPoint, Excel and Preview.

  • Runs on your computer. Nothing is uploaded.
  • No account to make or sign in to.
  • Works offline.
  • Launches fast and loads each editor only when you open that kind of file.
Download Writan Source on GitHub

For Mac (Apple silicon), Windows, Debian, Ubuntu and Fedora.

Why another document app

Word, PowerPoint and Preview are slow to open and heavy to keep running. Writan is built on Tauri, so it uses the web view your system already has instead of shipping a browser of its own. Word, PowerPoint and Excel files run on Writan's own document engine, written in Rust.

An editor for each kind of file

Every file opens as a tab. Each kind gets its own sidebar on the left and an inspector on the right, and ⌘\ hides them. On Windows and Linux, read Ctrl for ⌘.

WWord

Styles, fonts, colors, lists, line spacing, tables, images, links and page breaks. Headers and footers with page numbers. Comments with replies. Page size and margins, with A4 for new documents.

Calibri, Cambria, Arial, Times New Roman and Courier New are replaced by open-licensed fonts of the same widths, so lines break where Word breaks them.

PPowerPoint

Drag slide thumbnails to reorder them, and write speaker notes under each slide. Add text boxes, shapes, tables, images, video links and slides. Crop, rotate, flip, group, align and set transitions, then press Present.

XExcel and CSV

Type = in the formula bar to list functions and see what each one takes. Click or drag over cells, on any sheet, to put their references in the formula. Writan calculates about 140 common functions, including SUMIFS, XLOOKUP and IFS.

Make column, bar, line, area, pie, doughnut and scatter charts from the selected cells. CSV files open as one sheet and save as CSV.

PDFPDF

Highlight, add text, draw and place images. Sign with a signature you draw, type or photograph, and add initials, the date or a check mark. Fill in forms and jump to the next empty field.

Reorder, rotate, insert, extract and delete pages. Save a flattened copy so nobody can change the answers.

MMarkdown and text

Read, edit with a live preview, or edit the source, and switch with ⌘E. Front matter, such as an Agent Skill's name and description, shows as a table.

IMGImages and LaTeX

PNG, JPEG and HEIC open in a viewer with highlight, draw, arrow, box, crop and turn. The optional LaTeX plugin compiles with the TeX on your computer and shows source and PDF side by side.

In every tab

Autosave to the file itself
A saved file is written back to the same place a few seconds after you stop typing. If that folder is in iCloud Drive, Dropbox or OneDrive, the sync app uploads it. Writan signs in to nothing.
Version history
Each save keeps a copy on your computer. Compare any version with now, restore it, open it in a new tab or give it a name so it's always kept.
Tabs that come back
Open tabs return the next time you launch. Switch with ⌘1 to ⌘9, drag to reorder, or duplicate a tab to keep two parts of one document in view.
Split view
Put two Word documents or PDFs side by side with ⇧⌘\, such as a textbook's questions and its answers.
Find and replace
⌘F searches the document in front of you. Replace works in Word, PowerPoint, Markdown and text files.
Command palette
⌘K searches commands, open tabs and recent files. Type "dark" or "new markdown" and press Return.
Folders
Open a folder into a sidebar, as in a code editor, and search every document under it by name.
Focus mode
⌥⌘F hides everything but the page and fades every paragraph except the one you're writing. Typewriter scrolling keeps your line at one height.
A writan command
Run writan . to open a folder or writan a.pdf b.docx to open files from a terminal, as code does for VS Code.
Light, dark and your own themes
Follow the system or pick one, and make a theme from two tones and an accent.

Everything each editor can do and the keyboard shortcuts.

This is early software

Writan is mostly written by AI models, and it has bugs. LaTeX on Windows is still being tested. Some things it doesn't do yet:

  • Word: no spell check, and tracked changes can't be accepted or rejected.
  • Excel: pictures, conditional formatting and data validation aren't shown, though they're kept when you save.
  • PDF: signatures are pictures of your signature, not certificate signatures.
  • A crash loses edits you hadn't saved yet. Autosave and version history only protect saved changes.

Read the full list of what it doesn't do yet, and please open an issue when something breaks.

Download

The buttons below link to the latest release on GitHub.

  • Mac

    Apple silicon (M1 and later). Signed with a Developer ID and notarized by Apple.

    Open the .dmg and drag Writan to Applications.

    Download .dmg

  • Windows

    Windows 10 and 11, x64.

    Run the setup .exe. Writan isn't code-signed for Windows yet, so SmartScreen may say it protected your PC. Click More info, then Run anyway.

    Download .exe

  • Debian and Ubuntu

    Ubuntu 22.04 or Debian 12 and newer, x64.

    From the folder you downloaded it to:

    sudo apt install ./Writan_…_amd64.deb
    Download .deb

  • Fedora

    x64.

    From the folder you downloaded it to:

    sudo dnf install ./Writan-…x86_64.rpm
    Download .rpm

Writan keeps itself up to date. On Mac and Windows, new versions download in the background and install when you quit. The .deb adds Writan's APT repository and the .rpm its dnf repository, so updates arrive with your system's other updates. How updating works. Older versions are on the releases page.
